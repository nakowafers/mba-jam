# Multi-Season and Projected Baseline for Dynasty Value

Current-season Sleeper stats and single-week matchup projections return empty statlines for `0-GP` injured players and noisy outliers for tiny samples (`1–9 GP`), which previously collapsed valuable sidelined assets to `0.0` **Dynasty Value** in trade and **Roster** evaluations. We anchor **Dynasty Value** to a baseline blending prior-season actual MBA `FP/G` (weighted by prior games played up to `0.6` at `50+ GP`) with current-season full-season per-game projections, transitioning smoothly via a `0–10 GP` sample-size ramp (`sampleWeight = min(1, GP / 10)`) into the established `75%` actual / `25%` full-season projected blend at `10+ GP` (falling back to non-empty single-week projections only when full-season projections are absent). **Dynasty Value** applies no injury discount so Axis 1 preserves healthy long-term asset worth, whereas **Average Lock-In Score** and **Starting 10 Avg Lock-In** (Axis 2) remain strictly current-season (`0.0` at `0 GP`) per ADR-0003 so contender scoring accurately reflects active availability.
